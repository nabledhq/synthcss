SynthCSS

CSS designed to be written by machines and used by humans.

A lightweight, opinionated CSS framework: a small set of design tokens and intent-named layout primitives that respond to the space they are given, plus eight semantic components for common app UI.

Built for AI-generated interfaces. SynthCSS targets interfaces written by AI agents and code generators, so its vocabulary is small, semantic and predictable.

View on GitHub Read the docs

This page is built with SynthCSS itself. SynthCSS is crowdfunded on nabled.ai.

Why SynthCSS

  • Frameworks are built for humans

    Traditional frameworks are optimized for people hand-writing every class.

  • AI output is inconsistent

    Models generating free-form CSS produce different values and patterns every time.

  • A small, predictable vocabulary

    SynthCSS offers a few semantic tokens and classes that mean one thing each.

  • Designed for model ergonomics

    Class names state intent, so a model can map a request to markup reliably.

Components

Ten semantic components built only from tokens. State comes from native attributes such as disabled, aria-busy, aria-invalid, aria-current and aria-selected. Press Tab to see the focus rings.

AI Contract

One compact file teaches a model the whole public vocabulary of SynthCSS: every token, layout primitive, component, part and variant, an intent table, composition rules, ten generation rules and valid and invalid examples. Paste synthcss.llm.md into a prompt, or read the same contract as structured data from synthcss.ai.json. Both are versioned with the framework and checked against the CSS on every change.

View synthcss.llm.md Download synthcss.ai.json Read it on GitHub ≈ 3,490 tokens
